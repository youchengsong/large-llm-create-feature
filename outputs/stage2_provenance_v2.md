## 1. small_test_round_amount_ratio（小额测试+整数金额组合比例）

**维度**: 金额频次

**知识溯源**:
| 知识ID | 类型 | 内容摘要 |
|--------|------|---------|
| RULE_002 | 检测规则 | 休眠账户激活后先小额测试再大额交易 |
| RULE_015 | 检测规则 | 网络赌博资金100元整数倍，深夜交易 |
| IND_07 | 风险指标 | 多账户小额分散转账，拆分交易规避监管 |
| IND_21 | 风险指标 | 休眠账户突然激活并发生大额交易 |
| EXP_15 | 专家意见 | 线下跑分：四类匿名钱包ATM取现，上游开立数币钱包把钱转入后发账号密码给下游取现 |
| EXP_21 | 专家意见 | 线上跑分每日交易量达单钱包交易限额上限，持续10-30天 |
| PAT_A02 | 交易模式 | 线下跑分（ATM取现）：休眠→突然激活，取现金额整数 |
| PAT_A03 | 交易模式 | 线上跑分（钱包互转）：跑分金额300-5000元 |
| RF_S2_112_005 | 裁判文书 | 账户资金交易模式异常，表现为小额测试交易后大额资金快速进出 |
| RF_S2_177_005 | 裁判文书 | 卡主在短时间内收到多笔小额测试交易后出现大额资金流入 |

**设计推理**: 异常账户small_tx_ratio(≤5元)是正常的6倍，round_100_ratio是正常的3.64倍。RULE_002描述了休眠账户先小额测试后大额交易的模式，RULE_015描述了网络赌博资金100元整数倍特征。将两者乘积组合（small_tx_ratio × (1 + round_100_ratio)）可放大异常信号。

**数据字段**: `src`, `amount`, `transaction_motif`
