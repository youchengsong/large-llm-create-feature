\begin{abstract}
Automated feature engineering with large language models (LLMs) can produce semantically meaningful features for tabular data, yet existing methods lack structured domain knowledge, rigorous verification, and explainable provenance. We propose \textbf{KnowFeat}, a knowledge-guided feature engineering framework that addresses all three gaps. KnowFeat organizes domain knowledge into a five-type taxonomy (schema metadata, regulatory indicators, detection rules, expert opinions, and court document evidence) and injects it as structured context into an LLM agent. A three-stage verification pipeline filters candidates through code execution, statistical quality checks, and model effectiveness evaluation. Every accepted feature carries a provenance card linking its design to specific knowledge assets. On seven public benchmarks, KnowFeat achieves the best average rank (1.4) among eight methods. On a realistic anti-money laundering dataset (synthesized to match the statistical properties of production digital currency transactions) with 200K transactions, 18 verified features improve Recall by +2.1pp and F1 by +1.5pp, outperforming methods that generate over 1{,}000 unverified features. Code and data are available at \url{https://anonymous.4open.science/r/knowfeat-C967/} and \url{https://huggingface.co/datasets/anonymous-7219/knowfeat}.
\end{abstract}
