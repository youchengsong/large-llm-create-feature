\begin{abstract}
Automated feature engineering with large language models (LLMs) can generate semantically meaningful features for tabular data, yet existing methods lack structured domain knowledge, rigorous verification, and auditable provenance. We propose \textbf{KnowFeat}, the first knowledge-guided feature engineering framework that addresses all three gaps. KnowFeat organizes domain knowledge into a five-type hierarchy---from schema metadata to regulatory indicators, detection rules, expert opinions, and court document evidence---and injects it as structured context into an LLM agent. A three-stage verification pipeline filters candidates through code execution, statistical quality checks, and model effectiveness evaluation. Every accepted feature carries a provenance card tracing its design to specific knowledge assets, enabling the auditability required in regulated domains. On seven public benchmarks, KnowFeat achieves the best average rank (1.4) among seven methods. On a real-world anti-money laundering dataset with 200K transactions, 18 knowledge-guided features improve Recall by +2.1pp and F1 by +1.5pp over a 93-feature baseline, outperforming methods that generate up to 1,031 unverified features. Ablation studies confirm that hierarchical domain knowledge is essential for consistent feature generation.
\end{abstract}
