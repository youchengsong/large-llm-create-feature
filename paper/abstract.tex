\begin{abstract}
Automated feature engineering with large language models (LLMs) can produce semantically meaningful features for tabular data, yet existing methods lack structured domain knowledge, rigorous verification, and explainable provenance. We propose KnowFeat, a knowledge-guided feature engineering framework. KnowFeat organizes domain knowledge into five types---schema metadata, regulatory indicators, detection rules, expert opinions, and court document evidence---and injects them as structured context into an LLM agent to ensure grounded, relevant candidate feature generation. A three-stage verification pipeline then filters candidates through code execution, statistical quality checks, and model effectiveness evaluation. Every accepted feature carries a structured provenance record tracing its design rationale to specific knowledge assets. Under a strict held-out evaluation protocol that eliminates feature-selection leakage, KnowFeat achieves the best average rank across twelve public benchmarks among seven methods (one-sided Wilcoxon $p{=}0.040$), including a 11.6-percentage-point AUC improvement on a telecom churn dataset. On a real-world Bitcoin anti-money laundering (AML) dataset (Elliptic) and a synthetic digital currency AML benchmark (SimECNY), KnowFeat maintains competitive detection performance with full provenance traceability.
\end{abstract}
