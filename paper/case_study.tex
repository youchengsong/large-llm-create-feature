\subsection{Case 1: Fan-In/Fan-Out Ratio (Network Topology)}

\textbf{Feature:} \texttt{fan\_in\_fan\_out\_ratio}---asymmetry between incoming and outgoing transaction patterns, weighted by abnormal mode proportion. Uses 4 knowledge assets: \textit{RULE\_006} (scatter-in/gather-out layering), \textit{RULE\_013} (pyramid-shaped fund networks), \textit{PAT\_A03} (money mule behavioral pattern), and \textit{IND\_15} (abnormal transaction modes).

\textbf{Reasoning chain:} (1)~Compute fan-in/fan-out mode ratio per wallet from \textit{RULE\_006/013}. (2)~Weight by abnormal mode proportion from \textit{IND\_15}. (3)~Combine: $\text{ratio} \times (1 + \text{abnormal\_mode\_ratio})$.

\begin{lstlisting}
fi = mode_counts['fan_in'] / n
fo = mode_counts['fan_out'] / n
ratio = fi / (fo + eps)
abnormal = fi + m2m_ratio + o2m_ratio
result = ratio * (1 + abnormal)
\end{lstlisting}

This feature fuses four knowledge assets spanning three types (rules, patterns, indicators) to produce a topology-aware asymmetry score. No syntactic method would produce this---it requires understanding that directional imbalance combined with abnormal mode prevalence characterizes money mule behavior.

\subsection{Case 2: Cross-Dimensional Risk Interaction}

\textbf{Feature:} \texttt{high\_risk\_region\_off\_hour\_ratio}---multiplicative interaction between geographic risk and temporal anomaly. Uses 3 knowledge assets: \textit{RULE\_005/014} (cross-regional flows through border areas), \textit{IND\_08/09} (off-hour transaction concentration), and \textit{EXP\_05} (``border region + nighttime trading is the hallmark of cross-border laundering'').

\textbf{Reasoning chain:} (1)~Flag high-risk border regions from \textit{RULE\_005/014}. (2)~Compute off-hour ratio from \textit{IND\_08/09}. (3)~Neither signal alone is sufficient (\textit{EXP\_05}); multiply: $\text{is\_high\_risk} \times \text{off\_hour\_ratio}$.

\begin{lstlisting}
is_hr = region.isin([540000, 650000])
off = (hour >= 18) | (hour < 8)
off_ratio = off.sum() / n
result = is_hr * off_ratio
\end{lstlisting}

This feature demonstrates \emph{cross-dimensional interaction}: geographic context (account metadata) combined with temporal patterns (transaction logs), guided by expert knowledge. The multiplicative form ensures only the conjunction triggers a high score, exactly as the domain expertise prescribes. Both cases illustrate capabilities that syntactic methods cannot replicate, and both carry complete provenance chains for regulatory audit.
