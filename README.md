# 大模型提取特征

通过 LLM（大语言模型）从数据中提取丰富、高质量、可解释的特征，用于下游机器学习任务。

## 项目目标

利用 LLM 的语义理解和领域知识能力，自动发现和生成传统特征工程难以获取的高质量特征，同时保持特征的可解释性。

## 文献综述

详见 [LITERATURE_REVIEW.md](LITERATURE_REVIEW.md)，涵盖以下核心方法：

| 方法 | 代表论文 | 核心思路 |
|------|---------|---------|
| 文本→可解释特征 | Balek 2025 | LLM 直接提取语义特征值 |
| 表格→特征代码 | CAAFE, OCTree | LLM 生成特征转换代码 |
| 图→文本推理 | Pirmorad 2025 | 子图序列化 + ICL 推理 |
| 多 Agent 系统 | RiskTagger | 多模块 Agent 协同标注 |
